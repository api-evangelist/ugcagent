# UGC Agent API v2.2.0

Two ways in, one engine.

POST /v1/messages is the conversational surface: send a message, the agent
picks its tools and answers with prose plus any creators it found.

The resource endpoints are for products that build on the engine directly,
and they mirror the tabs of the web app:
- Lists: persistent, appendable creator collections (`/v1/lists`).
- Creator searches: background sourcing jobs with structured filters,
  partial results while running, and optional list targeting
  (`/v1/creator-searches`).
- Webhooks: signed push of `lead.added` and job events (`/v1/webhooks`).
- Automations: recurring lead sourcing into a list, or recurring trend
  research by email (`/v1/automations`).
- Chats: list, rename, read and delete the chats in your web app sidebar
  (`/v1/chats`).
- Creator CRM: every creator you saved, with pipeline stage, deal terms,
  notes, tasks and CRM lists (`/v1/leads`, `/v1/lead-lists`,
  `/v1/lead-exports`).
- UGC Database: browse already-sourced creators and unlock them into the
  CRM (`/v1/database`).
- UGC Brands: brands that run UGC creator programs, their attributed
  accounts, videos and playbook (`/v1/ugc-brands`).
- Creator Tracking: tracked accounts, their videos, collections and
  payouts (`/v1/tracking`).
- Applications: import, review and answer creator applications
  (`/v1/applications`).
- Outreach integrations: push creators into Instantly or Smartlead
  campaigns (`/v1/integrations`).
- Workspace: Agent Preferences, excluded creators and account usage
  (`/v1/preferences`, `/v1/account`).
- Research jobs: creator account analyses, creator enrichments, brand
  research and trend research (`/v1/creator-analyses`,
  `/v1/creator-enrichments`, `/v1/brand-researches`,
  `/v1/trend-researches`).

Plan gates mirror the app. When the workspace plan does not include 
feature, the call answers 402 with error.code `upgrade_required` and
error.required_plan naming the lowest plan that unlocks it.

The typical integration: create a list, register a `lead.added` webhook on
it, then start searches (or an automation) with `list_id` set. Every creator
that qualifies is appended to the list and pushed to the webhook as it
lands, and later searches never return anyone already in the list.

POST /v1/messages runs a turn and waits for the result. A turn that outruns
the wait window answers 202 with a Location header; poll it with
GET /v1/messages/{id} until stop_reason is no longer "pending".

API access is available to Ultra and Enterprise workspaces, neither of
which has a monthly credit ceiling. A turn that returns leads consumes
credits, which are metered per workspace and reported in
Account -> API -> Usage.

Ultra workspaces may make 100 job-creating calls per UTC day and 2,000 per
calendar month (UTC). Enterprise workspaces have no call caps. Premium
workspaces lost API access on 2026-09-08. Job-creating calls are:
POST /v1/messages, POST /v1/creator-searches, POST /v1/automations,
POST /v1/automations/{id}/runs, POST /v1/creator-analyses,
POST /v1/creator-enrichments, POST /v1/brand-researches,
POST /v1/trend-researches, POST /v1/application-reviews with
`analyze_accounts: true`, and POST /v1/application-video-analyses. An
idempotent replay or a call that fails before creating work is not
counted. Reads, polling and every other endpoint do not count against the
call quota (they are still rate limited per minute). Every job-creating
response carries X-Quota-Daily-Limit, X-Quota-Daily-Remaining,
X-Quota-Daily-Reset, X-Quota-Monthly-Limit, X-Quota-Monthly-Remaining and
X-Quota-Monthly-Reset. An exhausted window answers 429 with error.code
api_daily_quota_exceeded or api_monthly_quota_exceeded and a Retry-After
pointing at the reset. Enterprise workspaces have no call caps (the
headers read "unlimited").

Every response carries X-Request-Id; the same value is in error.request_id
on failures.

Team workspaces: every key addresses the workspace (the team owner's
lead pool, call quota, lists, webhooks, automations, creator searches and
research jobs). On per-person surfaces (Creator CRM, chats, outreach
integrations, Agent Preferences, applications, Creator Tracking) a key
acts as the team member who created it, like that member in the app.
Keys created before member attribution act as the workspace owner.

Idempotency: mutations accept an Idempotency-Key header. A completed key
replays its result for 24 hours; a duplicate that arrives while the first
request is still running answers 409 idempotency_in_progress with
Retry-After; only successes and 400/422 validation errors are stored, so 
5xx, 402, 404, 409 or 429 releases the key for a retry. Automations keep
their own receipt flow (a replay returns the stored automation or run).

Hosted MCP: the UGC Agent MCP server calls this same API on behalf of
Premium, Ultra and Enterprise users. Metered job endpoints (POST
/v1/messages, /v1/creator-searches, /v1/automations,
/v1/automations/{id}/runs and the four research jobs) answer MCP callers
403 not_available_on_mcp; MCP sourcing runs through its run_ugc_agent
tool, which draws on the plan's lead pool like the app.

## Product areas
- [Creator CRM](/#/creator-crm): saved creators as CRM leads (/v1/leads): pipeline stages, deal terms, notes, tasks, touches, CRM lists and CSV export; saving from the UGC Database costs 1 lead.
- [UGC Database](/#/ugc-database): browse the shared pool of already-sourced creators with filters and facets, emails masked until you unlock one (1 lead each, saved to your Creator CRM).
- [UGC Brands](/#/ugc-brands): read-only database of brands that run UGC creator programs: program facts, attributed creator accounts with evidence, brand videos and a playbook of what works. Plan-gated like the app.
- [Creator Tracking](/#/creator-tracking): track Instagram and TikTok accounts, read per-video views, virality and CPM, run collections (campaigns) and weekly payouts over /v1/tracking.
- [Applications](/#/applications): Import creator applications from form exports, review and rank them against your criteria, set statuses, draft replies (never sent) and analyze sample videos.
- [Outreach integrations](/#/outreach-integrations): Send unlocked creators to Instantly or Smartlead campaigns, list campaigns, and control auto-send. Vendor keys are connected in the app only.
- [Workspace, preferences & account](/#/workspace): Agent Preferences and excluded creators that shape every search, the account usage summary (plan, lead pool, API call quota), and chats (list, rename, read, delete).
- [Trend automations](/#/trend-automations): Scheduled trend research reports and lead sourcing automations over /v1/automations, with run results, test emails and delivery retries.
- [Research jobs](/#/research): Structured async jobs for one capability each: analyze a creator account, enrich creators by handle or URL, find a brand's verified creators, and research current trends; each POST is one job-creating call, poll the Location URL.

## Connectors
- [Meta Muse connector](/#/muse-connector): UGC Agent as an MCP connector for Meta Muse and other MCP clients. Endpoint https://mcp.ugcagent.app/mcp, Premium or higher (bearer API key on Ultra or Enterprise), full tool catalogue by area with plan, cost and confirmation flow, limits, data handling.
